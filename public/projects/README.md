Project screenshots live in this folder.

To use a real project picture:
1. Export a screenshot as PNG, JPG, WEBP, or SVG.
2. Put it in this folder.
3. In `constants.js`, set the project image path, for example:

```js
image: {
  src: '/projects/aureva-ecommerce.png',
  alt: 'Aureva e-commerce product page screenshot',
},
```

Recommended image size: 1600x900 or any 16:9 screenshot.
